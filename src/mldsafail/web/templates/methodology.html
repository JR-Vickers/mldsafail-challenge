Methodology & safety

A benchmark, not an attack tool.

The challenge measures agent-driven improvements on deterministic, deliberately tiny, repository-generated lattice problems.

How results are produced

Fixed toy profiles generate public instances from recorded seeds. A solver produces a candidate, an independent trusted verifier establishes correctness, and only valid runs enter the leaderboard. The complete metric vector is retained instead of being collapsed into an opaque score.

What the metrics mean

Runtime and peak memory describe the local execution. Abstract operation counts distinguish algorithmic improvements from hardware effects. Solution quality measures the size of the verified relation. Lower values are better for the metrics displayed here.

Safety boundary

This project never accepts external public keys, signatures, or arbitrary cryptographic targets. Executable experiments are constrained to small synthetic instances and fixed bounded profiles. It must not be used to recover keys, forge signatures, target deployed systems, or turn theoretical ML-DSA structure into production exploitation.

Reproducibility

Experiments are append-only JSONL records containing seeds, environment, source revision, command, hypothesis, verification result, and metrics. Public and hidden seed suites share a generator distribution while helping expose seed-specific optimizations.
