Check the live database with a read-only query after web admission is stopped and before any temporary coordinator start; reject queued/claimed/running work and restore original states independently on rejection. Then retain the existing source-bound epoch/run inventory audit. A dummy sleep-service fault suite does not exercise this application queue boundary.
